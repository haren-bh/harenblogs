Hands-on Lab / Google Cloud ADK & Agent CLI

Antigravityを利用しアプリやAIエージェントの作成

このハンズオン（ラボ）では、Google Cloud のツールを活用して、プロダクション環境に対応したエージェント型アプリケーションを構築する方法を学びます。

1. プロジェクトの設定 2. API の有効化 3. Agent CLI インストール 4. Antigravity CLI 起動 5. Gemini Notebook 調査 6. 仕様書の改善 7. コードを生成 8. テストと Cloud Run デプロイ 9. エージェントの構築 10. Playground テスト 11. Agent Platform デプロイ 12. 次のチャレンジ
Part 1

環境のセットアップ

プロジェクトの設定

  • 次のリンク GCP コンソールをクリックして、GCP コンソールに移動します。
  • 使用できるプロジェクトがまだない場合は、GCP コンソールで新しいプロジェクトを作成する必要があります。プロジェクト セレクタ（Google Cloud コンソールの左上）でプロジェクトを選択します。まだプロジェクトがない場合は、こちらの手順に沿って新しいプロジェクトを作成してください。新しいプロジェクトを作成したら、プロジェクトを選択してください。
  • このラボでは、Cloud Shell エディタを使用してタスクを実行します。Cloud Shell を開き、Cloud Shell を使用してプロジェクトを設定します。
  • このリンクをクリックすると、Cloud Shell エディタに直接移動します。
  • Cloud Shell エディタのサイドバーで、[フォルダを開く] ボタンをクリックします。
  • ホームフォルダはすでに選択されているはずです。[OK] を押すと、ホームフォルダがこのタスクのルートフォルダになります。
  • メニューから [Terminal] > [New Terminal] をクリックして、ターミナルを開きます（まだ開いていない場合）。このチュートリアルのコマンドはすべて、このターミナルで実行できます。
  • プロジェクトがすでに認証されているかどうかは、Cloud Shell ターミナルで次のコマンドを使用して確認できます。
Cloud Shell Terminal 
gcloud auth list
  • プロジェクト ID がわからない場合は、次のコマンドを使用してすべてのプロジェクト ID を一覧表示できます。
Cloud Shell Terminal 
gcloud projects list
  • プロジェクト ID をコピーし、次のコマンドを使用して設定します。
Cloud Shell Terminal 
gcloud config set project <YOUR_PROJECT_ID>
  • Cloud Shell で次のコマンドを実行して、プロジェクトを確認します。
Cloud Shell Terminal 
gcloud config list project

API を有効にする

このラボを実行するには、いくつかの API サービスを有効にする必要があります。Cloud Shell で次のコマンドを実行します。

Cloud Shell Terminal 
gcloud services enable aiplatform.googleapis.com
gcloud services enable cloudresourcemanager.googleapis.com

API の概要

  • Vertex AI API（aiplatform.googleapis.com）を使用すると、Vertex AI プラットフォームにアクセスできます。これにより、アプリケーションはテキスト生成、チャット セッション、関数呼び出しのために Gemini モデルを操作できます。
  • Cloud Resource Manager API（cloudresourcemanager.googleapis.com）を使用すると、プロジェクト ID や名前など、Google Cloud プロジェクトのメタデータをプログラムで管理できます。これは、プロジェクトの ID と権限を確認するために他のツールや SDK で必要になることがよくあります。

Agent CLIをインストール

Google Agent CLI（agents-cli）は、Agent Development Kit（ADK）を用いたエージェント型アプリケーションのプロジェクト作成、ローカルテスト、および Google Cloud Agent Platform へのデプロイを効率的に行うためのコマンドラインツールです。

Cloud Shell Editor のターミナルで以下のコマンドを実行します。

Cloud Shell Terminal 
mkdir myproject
cd myproject && uv venv
source .venv/bin/activate
uv pip install google-adk
uvx google-agents-cli setup

図 1 のような画面が表示されれば、Agent CLI のインストールは完了です。

Antigravity CLIの起動

Cloud Shell ターミナルで Antigravity CLI（agy）を起動します。認証や初期設定が求められた場合は、以下のステップに従って設定を行ってください。

Cloud Shell Terminal 
export AGY_ADC_AUTH=true && agy

起動すると、以下のような画面が表示されます。

注意：agy の設定時、ターミナルの表示領域が狭いと画面全体が表示できない場合があります。その際はターミナル画面を大きくしてください。

ターミナルパネルにある をクリックすると、ターミナル画面が大きくなります。

ヒント: Shift + Tab を押すと、ファイル変更の確認ステップをスキップし、コマンド実行の確認のみに短縮できます。

まずは Enter キーを押して terminal（テーマ）を選択し、スペースキーを押して Import extensions... を選択、下矢印キー（↓）を押して Next を選択し Enter キーを押します。

Done を選択し Enter キーを押します。

このまま Enter キー（Yes, I trust this folder）を押します。

これで Antigravity CLI が利用可能になります。

Part 2

Gemini Notebookを利用しアプリを調査する

エージェントやアプリケーションの実装に入る前に、Gemini Notebook を活用して事前の技術調査と仕様書（スペック）の作成を行います。あらかじめ要件を整理した Markdown 形式の仕様書を用意しておくことで、後続のステップで Antigravity CLI（agy）に正確なコンテキストを渡せるようになり、設計から実装までをスムーズに進められます。

1. 新しい Notebook を作成する

ブラウザで Gemini Notebook にアクセスし、[新しい Notebook] をクリックして新規ノートブックを作成します。

2. 調査したいトピックを決める

作成したいアプリケーションやゲームのテーマを決めます。以下は調査時に入力するプロンプトの例です。

  • 例 1：カメラ連動シミュレーションゲーム
    Gemini Notebook Prompt 
    カメラを使って野球ボールを投げるシミュレーションゲームの作り方について調べてください。
  • 例 2：2D アクションゲーム
    Gemini Notebook Prompt 
    以下のようなゲームの作り方について調べてください。
「Dino Dash」は、素早い恐竜を操作してプレイする、ハイオクタンな 2D カートゥーン・プラットフォーマーです。障害物を飛び越え、激しい攻撃をかわし、熱い炎のブレスで敵を焼き払いながら、ゴールを目指して駆け抜けよう！
  • 例 3：セキュリティ・脆弱性対策アプリ
    Gemini Notebook Prompt 
    直近のオープンソースソフトウェアで見つかった CVE（脆弱性情報）を動的に取得し、その対策方法を教えてくれるアプリの作り方について調べてください。

3. Deep Research で検索し、リソースをインポートする

  1. 画面左側の検索ボックスに上記のようなプロンプトを入力し、[Deep Research] を選択して検索を実行します。
  2. Web 上から関連する技術記事やドキュメントが自動収集されます。検索が完了したら、表示されたリソースを Notebook にインポートします。

4. Markdown 形式でスペック（仕様書）を作成する

インポートした技術リソースをベースに、Gemini Notebook のチャット欄でアプリケーションの仕様書（スペック）を作成します。後の開発工程で Antigravity CLI にそのまま読み込ませて活用できるよう、Markdown（.md）ファイル形式で出力してもらうことを推奨します。

チャット欄に以下のプロンプトを入力し、スペックを生成してください（〇〇 の部分には作成したいアプリの内容を入力します）。

Gemini Notebook Prompt 
〇〇をするアプリを作りたいです。以下の項目を含めて、Markdown 形式でスペック（仕様書）を作成してください。

- アプリの概要
- 必要なコンポーネント
- コンポーネントごとの機能要件
- 非機能要件
- テストケース

生成されたスペックは、手元の環境に spec.md というファイル名で保存しておきます。

Part 3

Cloud Shell EditorでMarkdownの仕様書を改善する

Gemini Notebook で作成した仕様書（spec.md）を Cloud Shell Editor に取り込み、Antigravity CLI（agy）を使って実装に最適化された仕様書へとブラッシュアップします。

  1. 仕様書ファイルのアップロード
    Cloud Shell Editor 左側のエクスプローラーで自分のプロジェクトフォルダ（例：myproject）を開き、保存した spec.md ファイルをフォルダ内へドラッグ＆ドロップしてアップロードします。
  2. Antigravity CLI による仕様書の改善
    Antigravity CLI（agy）に以下のプロンプトを入力し、仕様書のレビューと改善を依頼します（〇〇 の部分には作成したいアプリの内容を入力します）。
    Antigravity CLI Prompt 
    spec.md を利用して〇〇をするアプリを作成したいです。仕様書に不足している点や改善すべき箇所があればブラッシュアップしてください。
  3. 仕様書の最終チェック
    Antigravity CLI が spec.md を解析し、不足している技術要件や構成を自動的に改善します。更新された spec.md をエディタで開き、実装に入る前の最終チェックを行いましょう。

Part 5

テストと Cloud Run にデプロイ

コードの生成が完了したら、ローカル（Cloud Shell 上）で Flask アプリケーションの動作をテストし、問題がなければ Google Cloud Run へデプロイします。

1. Flask アプリケーションのローカルテスト

まず、Antigravity CLI（agy）に指示して、仕様書（spec.md）のテストケースに基づくテストの実行と、Flask 開発サーバーの起動を行います。

Antigravity CLI Prompt 
生成した Flask アプリのテストを実行し、ポート 8080 でローカルサーバーを起動してください。

（※別のターミナルから手動で起動する場合は、仮想環境を有効化した状態で python app.py または flask run --host=0.0.0.0 --port=8080 を実行します。）

サーバーが起動したら、以下のいずれかの方法でブラウザから画面と動作を確認します。

  • ターミナルに出力された http://localhost:8080（または http://127.0.0.1:8080）を Ctrl + クリック して開く
  • Cloud Shell Editor 右上の [ウェブでプレビュー]（Web Preview） アイコンをクリックし、[ポート 8080 でプレビュー] を選択する

画面の表示や各機能が spec.md の要件通りに動作しているか確認しましょう。もし修正したい点があれば、そのまま Antigravity CLI に伝えて修正させることができます。

2. Cloud Run へのデプロイ

ローカルでの動作確認が完了したら、Antigravity CLI（agy）に以下のプロンプトを入力して、アプリケーションを Cloud Run にデプロイします。

Antigravity CLI Prompt 
このアプリを Cloud Run にデプロイしてください。

Antigravity CLI が必要な設定（Dockerfile や依存関係の構成、必要な API の有効化、ビルドおよびデプロイコマンドの実行など）を自動的に処理します。数分ほどでデプロイが完了し、発行された Cloud Run の公開 URL（https://...run.app）からアプリケーションにアクセスできるようになります。

Part 6

最初のエージェントの構築

このラボの後半では独自のカスタムエージェントを設計しますが、まずは基本となるエージェントを構築してテストしてみましょう。

今回は、能登半島のトキに関する情報を検索・提供するエージェントを作成します。

Antigravity CLI に以下のプロンプトを入力してください。

Antigravity CLI Prompt 
agents-cli を使用して、Google 検索で能登半島のトキの情報を調べてくれるエージェントを作成してください。
トキ以外の質問には回答しないようにしてください。
挨拶された場合は、「能登のトキについてどのようなことを調べたいですか？」といった返答をしてください。

処理が完了すると、AGY は以下のような出力を生成します。

バックグラウンドでは、agents-cli が Python によるエージェント定義や各種設定、ローカル実行・プレイグラウンド用環境など、ADK プロジェクトに必要なボイラープレートを自動生成します。手動でコードを書く手間が省けるため、エージェントの振る舞いの定義にすぐ集中できます。

続いて、Antigravity CLI 上でプロンプトを入力し、エージェントの動作をテストしてみましょう。

Antigravity CLI Prompt 
「能登半島でのトキの野生復帰や放鳥の取り組みについて教えてください」というメッセージで私のエージェントをテストする

エージェントのロジックは app/agent.py ファイルで確認できます。

ヒント：Antigravity CLI を途中で終了した場合は、ターミナルで agy --resume を実行することで、いつでも過去のセッションを再開できます。

プレイグラウンド（Playground）

エージェントは Playground（ブラウザベースの Dev UI）でもテストできます。単に対話するだけでなく、セッション（sessions）の確認や各ターンのトレース（traces）のステップ実行など、内部動作を可視化できます。Antigravity CLI で次のように指示してください。

Antigravity CLI Prompt 
エージェントのプレイグラウンドを起動してください。その際、-allow_origins "regex:https://.*8080-.*\.cloudshell\.dev" オプションを付与してください。
Antigravity CLI Prompt (別表現) 
エージェントのプレイグラウンドを起動する, -allow_origins "regex:https://.*8080-.*\.cloudshell\.dev" オプションをつける

AGY がバックグラウンドで Playground を起動し、ローカル URL（通常は http://localhost:8080）を出力します。

表示された http://localhost:8080/dev-ui を Ctrl + クリック すると、UI 画面が開きます。

Agent Platform へのデプロイ

Google Cloud へのデプロイは、Antigravity CLI に対して Agent Platform へデプロイするよう指示するだけで完了します。

Antigravity CLI Prompt 
エージェントを停止してください。
Antigravity CLI Prompt 
エージェントを Agent Runtime にデプロイしてください。

デプロイには数分かかる場合があります。完了すると、Agent Platform 上でエージェントが確認できるようになります。

対象のエージェントをクリックすると、本番環境でのモニタリングや各種管理ツールを利用できます。
