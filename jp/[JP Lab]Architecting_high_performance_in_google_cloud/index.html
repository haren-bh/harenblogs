GOOGLE CLOUD HANDS-ON LAB

Antigravity で構築する高度な AI エージェントBuilding Advanced Agents with Antigravity

このハンズオンでは、Antigravity CLI（agy）への自然言語プロンプトを使って、記憶・地図検索・対話型 UI を備えた「レストラン探索 AI エージェント」を Google Cloud 上に構築します。In this hands-on lab, you use natural-language prompts in Antigravity CLI (agy) to build and deploy a Restaurant Discovery Agent on Google Cloud with persistent memory, live Google Maps search, and interactive UI.

  • Gemini 4 Neon + ADK エージェント：Google 検索と Google Maps を組み合わせて最適なレストランを探索するオーケストレーター。Gemini 4 Neon + ADK Agent: Orchestrates restaurant discovery by combining Google Search grounding with live Google Maps lookups.
  • Gemini Platform（Agent Runtime：Sessions & Memory Bank）：会話履歴（リモートセッション）とユーザーの食の好み（長期記憶）をクラウド上で永続化。Gemini Platform (Agent Runtime: Sessions & Memory Bank): Persists multi-turn sessions and long-term dining preferences across conversations.
  • Google Maps Platform API：Places API・Geocoding API・Maps JS API で実店舗の評価・価格帯・地図ピンを取得。Google Maps Platform APIs: Powers live place search, geocoding, ratings, and interactive map pins.
  • A2UI（Agent-to-UI）：チャット画面内に「好み登録フォーム」「半径指定マップ」「店舗比較パネル」を描画。A2UI (Agent-to-UI): Renders interactive preference forms, radius map pickers, and split-pane explorers directly inside chat.

学べること・事前準備What You'll Learn & Quick Notes

  • Antigravity CLI（agy）と 3 つの Agent Skills を使った、自然言語プロンプト中心のクラウド構築・エージェント開発。Prompt-driven cloud provisioning and agent coding with Antigravity CLI (agy) and three modular Agent Skills.
  • adk web でのローカル検証から、Gemini Platform Agent Runtime へのコンテナデプロイ・Playground 確認までの流れ。Testing locally in adk web and deploying your agent container to Gemini Platform Agent Runtime.
  • 必要なもの：個人の Gmail アカウント（Stage 1 で無料クレジットを取得可能）と Chrome などの最新ブラウザのみ。事前知識は不要です。What you need: Just a personal Gmail account (Stage 1 walks through claiming free credits) and a modern browser like Chrome—no prior ADK or A2UI experience required.

パート B：セッションと Memory Bank 用の Agent Runtime バックエンド作成Part B: Provision the Agent Runtime Session & Memory Bank Backend

ローカルデータベースに会話履歴を保存する代わりに、マネージドな Gemini Platform Agent Runtime（ReasoningEngine, GA）を構築します。単一のバックエンドでマルチターン会話用の Sessions（GA）とセッション横断の長期記憶 Memory Bank（Public Preview）の両方を利用できます。Instead of storing conversation history in a local database, provision a managed Gemini Platform Agent Runtime (ReasoningEngine, GA) resource providing both Sessions (GA) and Memory Bank (Public Preview).

  1. Antigravity CLI に以下のプロンプトを入力します。Enter the following prompt in the Antigravity CLI:

    Antigravity CLI Prompt • Session & Memory バックエンドの作成Antigravity CLI Prompt • Create Session & Memory Backend 
    In Agent Runtime Create a new backend to hold Session and Memory that our agent can use.

    us-central1 に advancedagents-session-memory-backend がプロビジョニングされ、4 つの標準マネージドトピック（USER_PERSONAL_INFO, USER_PREFERENCES, KEY_CONVERSATION_DETAILS, EXPLICIT_INSTRUCTIONS）が構成されたうえで、SESSION_SERVICE_URI と MEMORY_SERVICE_URI が .env に保存されます。Antigravity provisions advancedagents-session-memory-backend in us-central1 with four managed memory topics (USER_PERSONAL_INFO, USER_PREFERENCES, KEY_CONVERSATION_DETAILS, EXPLICIT_INSTRUCTIONS) and saves SESSION_SERVICE_URI and MEMORY_SERVICE_URI to .env.
