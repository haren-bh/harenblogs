Option A • Zero Setup Duration: ~1 Minute

Setting Up Google AI Studio

Recommended if you are new to Google Cloud and want to start building 3D web experiences immediately in your browser.

  1. Open Google AI Studio Apps (https://aistudio.google.com/apps) and sign in with your Google account.

  2. Enter your 3D build prompt directly in the prompt box, or upload a Markdown specification file (such as f1carracing.md, golfswing.md, or oceanflyby.md) to start generating and previewing your interactive 3D app live.

  3. Need a strong specification to upload? Jump to any of these resources:

Option B • Step 1 of 2 Duration: ~5 Minutes

Obtaining Google Cloud Free Credits & Creating a Project

Setting up Antigravity CLI involves two parts: (1) claiming your free Google Cloud workshop credits & project below, then (2) launching Antigravity CLI in Cloud Shell Editor.

Part A: Credit Claiming Procedure

  1. Log in to Google Cloud Console (https://console.cloud.google.com) using your PERSONAL Gmail account (do not use a corporate or school Workspace account).

  2. Locate the workshop credit redemption URL provided in the event materials (formatted like https://me.developers.google.com/benefits/claim/XXXX or https://g.dev/credits/XXXX).

  3. Open the redemption link, confirm you are signed in with your personal Gmail account, and click [Claim Credit].

  4. When prompted, complete the short form to set up your Google Developer Program profile.

  5. Scan the QR code on your mobile device to finish the human verification check.

  6. Once verification succeeds, a confirmation screen is displayed.

How to Check Claimed Credits (may take a few minutes to reflect)

Click [Open Billing Account] on the confirmation page, or open Cloud Billing in the Google Cloud Console. Your workshop credit account will appear under Billing Accounts.

Part B: Creating a Google Cloud Project

  1. Open the Google Cloud Console. In the top-left navigation menu (☰), select [IAM & Admin] > [Create a Project] (or open console.cloud.google.com/projectcreate directly).

  2. Complete the project configuration fields:

    • Project Name: Enter a descriptive name and note the generated Project ID—you will use it in Cloud Shell next.
    • Billing Account: Select your claimed Google Developer Program Credit Account. (Note: If you only have one billing account, Google Cloud links it automatically and hides this field.)
    • Parent Resource / Location: Select [No organization] (or an organization if applicable).

  3. Click [Create] and wait a few seconds for provisioning. When the top-right notification bell updates, click [Select Project].

  4. Confirm that your new project appears in the project selector pill at the top of the Google Cloud Console.

Optional: Save Your Project ID for Step 2 Commands

Type your Project ID below once—it will automatically populate gcloud config set project in the next guide so you can copy-paste directly.

Option B • Step 2 of 2 Duration: ~7 Minutes Total

Open Cloud Shell Editor, Enable APIs & Launch Antigravity CLI

The Antigravity CLI (agy) is an autonomous AI coding agent pre-installed in Google Cloud Shell that can architect, code, and verify multi-file 3D web applications right from your terminal.

Active Project ID Helper

Enter your Project ID to auto-fill the CLI commands below:

Stage 1: Open Cloud Shell Editor & Set Active Project

  1. In the Google Cloud Console, confirm your billing-enabled project is selected in the top-left project dropdown.

  2. Launch the Cloud Shell Editor (ide.cloud.google.com) directly (see Cloud Shell Editor documentation for background).

  3. In the left sidebar of Cloud Shell Editor, click Open Folder (if hidden, click the File Explorer icon on the far-left activity bar first), keep your home folder selected, and click OK.

  4. Open a terminal via Terminal > New Terminal in the top menu, then verify authentication and configure your active project:

    Cloud Shell Terminal • Verify Auth & List Projects 
    gcloud auth list
gcloud projects list
    Cloud Shell Terminal • Set & Confirm Project 
    gcloud config set project <YOUR_PROJECT_ID>
gcloud config list project

Stage 2: Enable Required APIs (~2 Minutes)

Enable Vertex AI and Cloud Resource Manager in Cloud Shell so Antigravity CLI can call Gemini 4 models using your project quota:

Cloud Shell Terminal • Enable APIs 
gcloud services enable \
    aiplatform.googleapis.com \
    cloudresourcemanager.googleapis.com

Stage 3: Create Your 3D Workspace & Launch Antigravity CLI (~5 Minutes)

Create a clean Python virtual environment for your 3D project (you can also pair agy with Agents CLI and Agent Development Kit (ADK) when building agent-backed apps):

  1. Install uv and initialize your ~/gemini43d project folder:

    Cloud Shell Terminal • Workspace Setup 
    # Install uv if you do not have it installed yet
pip install uv

# Create the project folder and a Python virtual environment
mkdir -p ~/gemini43d
cd ~/gemini43d && uv venv
source .venv/bin/activate
    Note: If you ever restart your Cloud Shell terminal, return to your workspace and re-activate the environment with cd ~/gemini43d && source .venv/bin/activate.

  2. Configure Application Default Credentials (ADC) mode and launch agy:

    Cloud Shell Terminal • Launch Antigravity CLI 
    export AGY_ADC_AUTH=true
agy
    Terminal Size Tip: Enlarge the bottom terminal panel before launching agy so the interactive first-run setup screens render cleanly without clipping.

  3. Complete the quick 3-prompt first-launch onboarding inside agy (arrow keys + Enter):

    • Select a color theme (e.g., terminal, light, or dark).
    • Accept the Terms of Service.
    • Select Yes, I trust this folder to authorize file creation inside ~/gemini43d.
    View First-Launch Onboarding Screenshots (Figures 7–10)
Antigravity CLI Power Shortcuts: Press Shift+Tab to auto-approve file edits so you only confirm shell commands. Run /model to inspect or switch Gemini 4 models. Exit anytime with /quit and resume your exact session later with agy --resume. Once your web server runs in Cloud Shell (e.g. port 8080), click Cloud Shell's Web Preview icon in the top-right toolbar to play your 3D app live!

Spec Engineering • Stage 1 NotebookLM Deep Research

Researching & Creating Your Initial Specification Document

Great 3D artifacts start with grounded engineering specifications. Use NotebookLM to research rendering, physics, and procedural techniques before generating your initial .md blueprint.

  1. Go to NotebookLM (https://notebooklm.google) and create a New Notebook.

  2. In the Source / Research search box, run a Deep Research query on the 3D rendering, physics, or animation techniques your project needs:

    NotebookLM Deep Research Prompt 
    Research for the methods needed to create 3D realistic animations with realistic textures.

  3. Once NotebookLM synthesizes the sources, ask it to draft your initial Markdown specification file:

    NotebookLM Initial Spec Prompt 
    Create a f1carracing.md to create specifications to build a visually stunning web based f1 racing game. The car should be controllable with wasd keys.

Interactive 3D Spec Prompt Composer

Spec Engineering • Stage 2 Gemini + Nano Banana Upgrade

Improving & Modifying the Specification Document

Before handing your spec to AI Studio or Antigravity CLI, use Gemini to enrich it with explicit Nano Banana texture manifests, deterministic physics equations, and difficulty presets.

  1. Open Gemini (https://gemini.google.com).

  2. Upload your initial Markdown specification file (either your NotebookLM draft or one of the sample .md specs you want to modify).

  3. Prompt Gemini to upgrade the specification with Nano Banana realistic textures, solid game physics, and difficulty levels:

    Gemini Spec Enhancement Prompt 
    Improve this specification file, make sure to include the textures using nanobanana for the realistic look and the game physics should be good along with game difficulty levels.
