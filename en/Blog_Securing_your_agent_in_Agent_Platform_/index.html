Securing your agent in Agent Platform with Agent Gateway and Model Armor

About the Gemini Enterprise Agent Platform

The Gemini Enterprise Agent Platform is a managed ecosystem for developing, deploying, and managing enterprise-grade AI agents.

  • Build: Developing intelligent agents using the Agent Development Kit (ADK) and integrating them with generative models.
  • Scale: Deploying and running agentic workloads across distributed systems with high performance and reliability.
  • Govern: Implementing comprehensive security, access control, and compliance policies—such as Model Armor and Agent Gateway—to ensure safe autonomous execution.
  • Optimize: Continuously enhancing agent performance and reliability through rigorous evaluation, monitoring, and feedback loops.

Governing your Agent

As the number of agents in your organization increases, tracking and securing them against external threats becomes increasingly challenging. The Govern layer in the Agent Platform provides a centralized environment for managing your fleet of agents at scale, offering a comprehensive suite of tools to ensure secure, reliable operation. Here are some of the tools the Govern layer provides to help you Govern your agents at scale.

Agent Identity

Agents deployed on Agent Runtime and Gemini Enterprise are automatically assigned a unique, cryptographically-attested identity. This system promotes a least-privilege approach to agent permissions and provides strong mitigation against access token theft by binding tokens directly to the agent runtime. Furthermore, it ensures non-repudiable auditing of all agent actions, while the Agent Runtime fully manages the identity lifecycle to eliminate the security threats posed by dormant credentials.

Agent Gateway

Agent Gateway serves as a central control tower for your agent ecosystem, allowing you to define, apply, and enforce security policies across all agent tools with consistent oversight. By integrating with Model Armor, the gateway provides inline protection to safeguard agent interactions against prompt injection and data leakage.

Model Armor

Model Armor is a governance and security feature within the Gemini Enterprise Agent Platform that provides integrated inline protection. It acts as a safeguard for agent interactions, specifically helping to protect against vulnerabilities like prompt injection and data leakage.

Securing your Agent with Model Armor

In this blog I will describe how you can use Model Armor with Agent Gateway to protect your agents against threats such as Prompt Injection and Data Leakage.

Once an agent is deployed in the Agent Runtime, Model Armor is implemented via the Agent Gateway at two primary enforcement points. Ingress protection intercepts external traffic at the Agent Gateway to inspect incoming requests before they reach the runtime. Egress protection monitors outbound traffic from the Agent Runtime toward other Google Cloud services, ensuring all external interactions are scanned for security compliance. In this blog I will focus on the protection from the ingress traffic.

5. Step-by-Step Implementation & Configuration

A production-ready setup requires precise alignment of regional resources and service identities.

5.1.Deploy your Agent

Build and deploy your agent in the Agent Runtime. Once you deploy you can find your deployed agent in the Agent Platform>Agents>Deployments.

You can use one of the several methods to create an agent such as, Agent Studio or Agent Development Kit. 

5.2. Creating Model Armor

You need to create a new Model Armor template in order to use it with Agent Runtime. Go to Model Armor and click on “Create Template”.
Enter Template ID and enable the protections as shown in figure below. Make sure you pick the same region as your Agent and note your Model Armor ID.



5.2. Create an Agent Gateway

To create an Agent Gateway, navigate to the Gateway page within the Agent Platform and click Add Gateway. When configuring your gateway, enable Model Armor and select the template you created previously. This ensures all incoming traffic is inspected by Model Armor before being passed to your agent.

5.2. Attaching Agent Gateway to your Agent

Now the Agent Gateway is created you need to attach Agent Gateway to your Agent. You can do this while creating a new Agent or you can attach it to the existing agent.

5.4. Making Authenticated Access to Agent via Agent Gateway

The gateway uses mutual TLS (mTLS) to ensure encrypted transport. You must upload your Root CA to the Certificate Manager Trust Config as a "Trust Anchor." The Agent Gateway configuration must then explicitly reference this Trust Config ID to authorize client certificates.

Clients must target the mTLS endpoint (https://REGION-aiplatform.mtls.googleapis.com).

If your enterprise uses self-signed certificates for internal client clients, the Google Cloud Ingress Gateway will reject them by default unless the signing Root Certificate Authority (CA) is trusted. To authorize these certificates, administrators must upload the Root CA (.pem) to the Google Cloud Certificate Manager under a Trust Config and associate that config with the Agent Gateway ingress setup.

You can create self signed certificates and upload certificates by following the following steps.

Step 1: Create the Private Root Certificate Authority (Root CA)

First, generate the 4096-bit RSA private key for the Certificate Authority and create a self-signed root certificate:

# 1. Generate the Root CA private key (kept strictly secure)

openssl genrsa -out rootCA.key 4096

# 2. Generate the self-signed Root CA certificate (valid for 10 years)

openssl req -x509 -new -nodes \

  -key rootCA.key \

  -sha256 \

  -days 3650 \

  -out rootCA.pem \

  -subj "/C=US/ST=California/L=Sunnyvale/O=GoogleCloud/OU=AgentSecurity/CN=AgentEngineRootCA"

This will create following keys
rootCA.key: Root private key used to sign client certificates.
rootCA.pem: Root CA public certificate configured on the Gateway's trust store.

Step 2: Generate the Client Private Key and Signing Request (CSR)

Next, create the credentials for the client application attempting to reach the agent:

# 1. Generate a 2048-bit RSA client private key

openssl genrsa -out client_key.key 2048

# 2. Create a Certificate Signing Request (CSR) with client identity metadata

openssl req -new \

  -key client_key.key \

  -out client.csr \

  -subj "/C=US/ST=California/L=Sunnyvale/O=GoogleCloud/OU=AgentClient/CN=imagescoring-client"

This will create following keys and CSR
client_key.key: Private key used by the client for TLS handshake negotiation.
client.csr: CSR containing client identity and public key to be signed by the Root CA.

Step 3: Sign and Issue the Client Certificate

Sign the CSR with the Root CA to generate the final client certificate:

# Sign the CSR using the Root CA and generate serial tracking file (rootCA.srl)

openssl x509 -req \

  -in client.csr \

  -CA rootCA.pem \

  -CAkey rootCA.key \

  -CAcreateserial \

  -out client_cert.pem \

  -days 825 \

  -sha256

client_cert.pem: The issued X.509 client certificate containing the client's public identity signed by the Root CA.

Step 5: Making the mTLS request to Agent Gateway

We can now make mTLS-authenticated requests to our agent. These requests pass through a Model Armor layer before reaching the agent, ensuring that all malicious requests are blocked.

Summary

To securely scale AI within the Gemini Enterprise Agent Platform, organizations must establish a governed ecosystem rooted in unique cryptographic agent identities and least-privilege access. Agent Gateway acts as the central control tower for policy enforcement, while Model Armor delivers inline protection against vulnerabilities like prompt injection and data leakage. Implementing this architecture requires regional alignment of security templates, strict IAM configuration, and mandatory mTLS using registered Trust Anchors. Finally, continuous log monitoring is critical to detect configuration errors and prevent unauthorized bypasses, ensuring autonomous execution remains secure.

def get_access_token() -> str:

    """Retrieve Google Cloud OAuth access token using google.auth (ADC/Service Account) with gcloud fallback."""

    try:

        import google.auth

        import google.auth.transport.requests

        credentials, _ = google.auth.default(

            scopes=["https://www.googleapis.com/auth/cloud-platform"]

        )

        auth_req = google.auth.transport.requests.Request()

        credentials.refresh(auth_req)

        if credentials.token:

            return credentials.token

    except Exception as e:

        print(f"google.auth token fetch failed: {e}")

    try:

        return subprocess.check_output(

            ["gcloud", "auth", "print-access-token"]

        ).decode("utf-8").strip()

    except Exception as e:

        print(f"gcloud auth token fetch failed: {e}")

        return None

def run_mtls_agent_test(

    prompt: str = None,

    user_id: str = None,

    agent_id: str = None,

    project_id: str = None,

    location: str = None,

    mtls_endpoint: str = None,

    cert_path: str = None,

    key_path: str = None,

    gateway_proxy: str = None

) -> dict:

    """Executes a query against the Agent via mTLS Gateway with Agent Armor / Cloud Armor active.

    Returns dict containing execution status, whether blocked by armor, error message, and events.

    """

    start_time = time.time()

    proj_id = project_id or PROJECT_ID

    loc = location or LOCATION

    target_agent_id = (agent_id or AGENT_ID).split("/")[-1]

    endpoint = mtls_endpoint or MTLS_ENDPOINT

    cert_file = cert_path or CLIENT_CERT_PATH

    key_file = key_path or CLIENT_KEY_PATH

    proxy = gateway_proxy if gateway_proxy is not None else GATEWAY_PROXY

    proxy_dict = {"http": proxy, "https": proxy} if proxy else None

    uid = user_id or f"user_mtls_{int(time.time())}"

    access_token = get_access_token()

    if not access_token:

        return {

            "status": "ERROR",

            "blocked_by_armor": False,

            "error_message": "Failed to retrieve GCP OAuth access token",

            "events_count": 0,

            "events": [],

            "duration_seconds": round(time.time() - start_time, 2)

        }

    if not (os.path.exists(cert_file) and os.path.exists(key_file)):

        return {

            "status": "ERROR",

            "blocked_by_armor": False,

            "error_message": f"Client certificates missing at cert={cert_file}, key={key_file}",

            "events_count": 0,

            "events": [],

            "duration_seconds": round(time.time() - start_time, 2)

        }

    url = f"{endpoint}/v1beta1/projects/{proj_id}/locations/{loc}/reasoningEngines/{target_agent_id}:query"

    headers = {

        "Authorization": f"Bearer {access_token}",

        "Content-Type": "application/json"

    }

    payload = {

        "class_method": "create_session",

        "input": {

            "user_id": uid

        }

    }

    blocked_by_armor = False

    status = "SUCCESS"

    error_message = None

    events_log = []

    try:

        response = requests.post(

            url,

            headers=headers,

            json=payload,

            cert=(cert_file, key_file),

            proxies=proxy_dict,

            timeout=30

        )

        if response.status_code == 403 or "Model Armor" in response.text or "PERMISSION_DENIED" in response.text:

            status = "BLOCKED"

            blocked_by_armor = True

            try:

                resp_json = response.json()

                error_message = resp_json.get("error", {}).get("message", response.text)

            except Exception:

                error_message = response.text

        elif response.status_code != 200:

            status = "ERROR"

            error_message = f"HTTP {response.status_code}: {response.text}"

        else:

            try:

                resp_data = response.json()

                events_log.append(resp_data)

            except Exception:

                events_log.append(response.text)

    except requests.exceptions.SSLError as ssl_err:

        status = "ERROR"

        error_message = f"SSL Handshake Error: {ssl_err}"

    except Exception as e:

        status = "ERROR"

        error_message = str(e)

    duration = round(time.time() - start_time, 2)

    return {

        "status": status,

        "blocked_by_armor": blocked_by_armor,

        "error_message": error_message,

        "events_count": len(events_log),

        "events": events_log,

        "duration_seconds": duration

    }
